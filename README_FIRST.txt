GL121123 Inspector - Galaxy Tab A11 app (T1.0)
===============================================
Stand-alone inspection on the tablet: tablet camera, all measuring on the tablet,
works offline after the first start. No laptop needed in production.

Open docs/GUIDE.html (double-click on the laptop) for the full step-by-step guide.

Short version:
 1. Upload EVERYTHING inside this folder to GitHub Pages (guide step 3) -> https address
 2. Tablet: Chrome -> open the address -> allow camera -> menu -> Add to Home screen
 3. Setup tab: camera, lock focus, inspection area
 4. Training tab: enter master true values -> Setup: "Measure master -> set scale"
 5. Training tab: capture master 12-20x at different places -> Analyse -> Apply
 6. Inspect tab: place part, take hand away, 2 s later OK / NG

Settings password: 1234 (change it).
